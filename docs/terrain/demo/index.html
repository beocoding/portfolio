Procedural Terrain

Built in Rust · Bevy ECS · WebGPU

How it works

Multi-draw indirect Every visible tile is drawn in a single GPU call via multi_draw_indirect. CPU overhead stays O(1) regardless of how many tiles are on screen.
Fractal noise Heightmaps are generated from layered fractal noise, normalized and meshed into triangle-strip tiles on the fly.
Slot-map instance manager A custom slot-map tracks tile GPU buffer slots, allowing tiles to be spawned and despawned without fragmenting the vertex pool.
Double-buffered uploads Dirty tiles are written to a staging buffer and flushed to the GPU with a swap, keeping the render world a strict one-directional consumer.
In-app settings panel Noise offset, octaves, and seed are all live-tunable from the on-screen panel — no recompiling, no reload.
WebGPU Compiled from Rust to wasm32 via Trunk. Indirect draw calls aren't expressible in WebGL2, so this demo targets WebGPU specifically.

Controls: WASD to move, mouse wheel to zoom, Q/E and R/F to rotate the camera. Adjust the noise settings in the on-screen panel to reshape the terrain live.
